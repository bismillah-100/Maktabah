## Features

- **Apple Notarized** — Secure and verified for macOS.
- **CloudKit Real-Time Sync** — Seamlessly sync annotations, highlights, and bookmarks across devices.
- **Complete Library Access** — Full access to the Maktabah Syamilah text archives.
- **Full-Text Search (FTS)** — Fast, multi-archive search capabilities.
- **Arabic Light10 Stemming** — Intelligent stemming integrated for accurate FTS indexing and search queries.
- **Annotations & Highlights** — Highlight passages, add notes, and organize research.
- **Multi-Tab & Multi-Window** — Flexible workspace for cross-referencing multiple books.
- **Reader Customization** — Adjustable Arabic typography, font size, and harakat display.
- **In-App Book Updates** — Download and update book archives effortlessly.
- **Light & Dark Mode** — Native dual-platform interface support.
